# Prepared CurseForge project copy

Name: **Nexus: Gear & Preparation**

Summary: A focused Retail companion for recommended gear, equipment ownership and Mythic+ preparation.

## Description

Nexus brings your gear goals and character preparation into one compact World of Warcraft window.

### Gear at a glance

Browse recommended gear for Mythic+ across supported specializations, including items acquired from dungeons, raids and crafting. A clear slot list shows each item and whether your current character has it equipped, carries it in bags, or is still missing it. Select an item for acquisition details, alternatives and a link into the Adventure Guide where available.

### Prepare your character

Review enchantments, equipped sockets, gem suggestions and consumables. Preparation follows your actual character; browsing another class shows source recommendations without inventing an equipped loadout.

### Understand the source

Recommendations are bundled snapshots. Nexus shows source names and dates. Gear popularity is not a personalized simulation. Mythic+ meta uses published Murlok rankings within each role. Raid mode and raid Meta are temporarily removed.

### A restrained Warcraft interface

Native game icons, tooltips and fonts, a consistent dark frame, a single gear list and a dedicated item detail pane. No player-profile browser or talent database is loaded.

### Commands

- `/nexus` — open Nexus
- `/nexus debug` — copy diagnostics
- `/nexus resetui` — reset window placement and size

### Preview status

This is a development preview. Real-client rendering and combat behavior are still being verified. Supported patch and source dates are shown in-game. No external network requests are made by the addon inside WoW.
